# solar-ios-app-test-maintainer
Reproducible iOS test-maintenance experiments using Upstage Solar Agent on a tile-matching app.

## Provenance

The BeachPang app source, tests, and Xcode project were imported from
[Hamjoon/tile-matching-ios](https://github.com/Hamjoon/tile-matching-ios)
at commit `cd9789b83bc6c0f6a791c0ebd0a42f4407ff25cc`, unmodified except that the
source repository's README was relocated to [docs/BeachPang-README.md](docs/BeachPang-README.md).
